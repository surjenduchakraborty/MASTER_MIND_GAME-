Master Mind Game – Short Description

This is a Python-based number guessing game inspired by the classic Mastermind.

The computer randomly selects a 4-digit secret number, and the player must guess it within 10 rounds.

After each guess, correctly placed digits are revealed.

If all digits match, the player wins.

If not guessed within 10 rounds, the player loses.

After losing, the correct number is shown, and the player can choose to play again.

The program also:

Greets the player by name and gender.

Displays a time-based greeting (Good Morning/Afternoon/Evening).

Adds nice visual formatting and a hint after 5 rounds.
